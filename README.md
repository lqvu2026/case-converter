# Case Converter

A small, single-page web app for changing the case of text. Works well with Vietnamese (diacritics are preserved and converted correctly).

## Features

- Sentence case, lower case, UPPER CASE, Capitalized Case, aLtErNaTiNg cAsE, Title Case, InVeRsE CaSe
- Live character, word and line counts
- Copy, Share, Download as .txt, Clear
- Undo the last conversion
- Settings: remember text on this device, dark theme

## Files

- `index.html` – the whole app (no build step, no dependencies)
- `case-converter-icon.png` – 180x180 Home Screen icon (add your own, with this exact name)
- `README.md`

## Publish on GitHub Pages

1. Put `index.html` and `case-converter-icon.png` in a GitHub repo.
2. Commit both files (editing a local copy alone does nothing until it is committed).
3. Repo Settings → Pages → deploy from the `main` branch, root folder.
4. Wait 1–2 minutes, then open the Pages URL.

## Add to iPhone Home Screen

Open the page in Safari → Share → Add to Home Screen. If you see a gray letter instead of the icon: delete the old shortcut, quit Safari, reload the page, and add it again.
